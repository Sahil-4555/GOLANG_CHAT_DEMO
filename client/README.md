# Chat Application Frontend in ReactJS

This project demonstrates the integration of a React frontend with a Go backend using Websocket for real-time communication. It utilizes Redux Thunk for managing local state, Axios for API calls, and Tailwind CSS for styling.

## Features

- Real-time communication between React frontend and Go backend using Socket.IO.
- Redux Thunk for managing local state and asynchronous actions.
- Axios for making HTTP requests to the backend.
- Tailwind CSS for styling the frontend components.
